# Validation

Criterios de aceitacao, metodologia de validacao e comparacoes com ferramentas de referencia.

## O que depositar aqui

- Criterios de aceitacao mensuraveis (ex: "F0 deve ter erro < 3% vs. Praat")
- Resultados de comparacao: nosso sistema vs. ferramenta de referencia
- Relatorios de validacao com metricas (precisao, recall, erro medio)
- Casos de teste de aceitacao do usuario
